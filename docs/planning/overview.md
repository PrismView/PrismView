# PrismView 기획 개요

개인용 차트·백테스트 플랫폼. 1차 목표는 OKX BTC/ETH 무기한 선물에서 **차트 + 지표 + 시그널 + 백테스트**를 같은 가격 데이터로 완성하는 것이다.

성공 기준: 기존 TradingView 전략과 같은 기간·같은 시간봉에서 진입·청산 내역과 총 PnL이 수수료 차이 범위 안에서 일치한다.

루트의 원본 기획서(`PrismView PRD.md`)는 개인 문서로 저장소에 올리지 않는다. 공개 허브에는 이 개요와 [의사결정 시트](decision-sheet.md), [ADR](../adr/README.md)만 둔다. 커스텀 30초봉은 기획 당시 보류였으나, 수집기 1단계에서 [ADR-0002](../adr/0002-30s-candle.md)로 범위를 연다.

## 포함

- OKX BTC-USDT-SWAP, ETH-USDT-SWAP
- 수집: 1초봉 백필·증분, 30초봉 집계, 누락 검사, Parquet 내보내기
- 차트: Lightweight Charts v5, 종목·시간봉 전환, 과거 스크롤, 실시간 갱신
- 드로잉: 추세선, 레이, 수평·수직선, 사각형, 텍스트 (시간·가격 좌표)
- 지표: SMA, EMA, 볼린저 밴드, RSI, MACD (Pine과 같은 계산)
- 시그널: 마감된 봉으로 계산한 가격 레벨 도달 시 진입·청산 (리페인팅 없음)
- 백테스트: 실시간과 같은 전략 코드, 지정가 체결 모델, 수수료·펀딩비

## 이번 버전에 하지 않음

- 13분·33분 등 30초 이외의 커스텀 봉
- BTC·ETH 외 종목, 현물
- 다중 사용자·로그인
- 알림, 파라미터 최적화, 멀티 타임프레임 전략
- 모바일
- 실시간 WebSocket 수집 (1차 수집기는 REST 백필·증분)

## 기능 메모

시그널은 직전 마감 봉까지로 레벨을 계산하고, 실시간 가격이 레벨에 닿으면 확정한다. 주문은 지정가이며, 한 봉 안에서 손절과 목표가가 동시에 닿으면 더 짧은 봉으로 순서를 보고 그래도 모르면 손절을 우선한다.

백테스트 요약은 총 PnL, 최대 손실폭, 승률, Profit Factor, 자산 곡선, 거래 목록(MFE/MAE)이다.
